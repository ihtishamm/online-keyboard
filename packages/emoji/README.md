# @okb/emoji

Emoji list, skin tones and search keywords for the emoji panel.

`data/` is generated by `pnpm --filter @okb/emoji build:data` from pinned Unicode sources,
downloaded once into `.cache/` (git-ignored):

- [emoji-test.txt](https://unicode.org/Public/emoji/16.0/emoji-test.txt) (Emoji 16.0): order,
  groups and skin-tone variants. Emoji newer than 15.0 are left out so phones a few years old
  can draw every one.
- [CLDR annotations](https://github.com/unicode-org/cldr/tree/release-49/common/annotations)
  (release 49, plus `annotationsDerived`): names and keywords in English, Urdu, Arabic, Farsi,
  Pashto, Sindhi, Shahmukhi (gaps filled from Urdu), Hindi and Bangla. Saraiki, Balochi and
  Kashmiri pages search the Urdu keywords.

| File            | Size      | gzip     |
| --------------- | --------- | -------- |
| `emoji.json`    | 147 KB    | 44 KB    |
| `<locale>.json` | 90-250 KB | 24-50 KB |

The web app loads `emoji.json` and the page language's keywords only when the panel opens.
