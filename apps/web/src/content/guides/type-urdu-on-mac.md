Every Mac can type Urdu. macOS calls keyboards "input sources": you add Urdu once, then switch between English and Urdu from the menu bar or with a key. This guide covers recent versions of macOS, with a note for older ones.

**Just need a few lines?** The [online Urdu keyboard](/urdu) works in Safari and Chrome on a Mac with nothing to set up. Type, then copy the text wherever you need it.

## Add the Urdu input source

1. Open the Apple menu and choose **System Settings**.
2. Select **Keyboard** in the sidebar.
3. Under **Text Input**, find **Input Sources** and select **Edit…**.
4. Select the **+** button at the bottom of the list.
5. Search for `Urdu`, choose the Urdu keyboard, and select **Add**.

On older versions of macOS (before Ventura), the same setting is in **System Preferences → Keyboard → Input Sources**, with the **+** button under the list.

While Input Sources is open, turn on **Show Input menu in menu bar** if it is off. It puts a small flag or letter icon near the clock that tells you which keyboard is active.

## Switch between English and Urdu

- Select the Input menu in the menu bar and choose **Urdu** or your English keyboard.
- Press <kbd>Control</kbd> + <kbd>Space</kbd> to switch to the previous input source. Press it again to switch back.
- On newer Mac keyboards, press the <kbd>Globe</kbd> (<kbd>fn</kbd>) key, if it is set to change the input source under **Keyboard** settings.

If a shortcut does nothing, check **Keyboard → Keyboard Shortcuts → Input Sources** in System Settings. Another app may be using the same keys.

## Find letters with the Keyboard Viewer

The Urdu keyboard on a Mac is its own layout, not one you will know from Windows, and the letters printed on your keys are English. To see where each Urdu letter is:

1. Switch to Urdu.
2. Open the Input menu in the menu bar and choose **Show Keyboard Viewer**.

A small keyboard appears on screen showing the Urdu letter on every key. Hold <kbd>Shift</kbd> or <kbd>Option</kbd> and the viewer updates to show the extra letters and marks on those layers. You can click keys in the viewer too.

If you would rather type with a layout where letters follow their sounds (<kbd>s</kbd> for <span lang="ur">س</span>, <kbd>p</kbd> for <span lang="ur">پ</span>), the [online Urdu keyboard](/urdu) uses the Phonetic layout. Print the [Phonetic chart](/cheat-sheets/urdu-phonetic) to keep beside you while you learn it.

## Get Nastaliq instead of Naskh

Apps often show Urdu in a plain Naskh style, which looks like Arabic to most Urdu readers. Urdu books and newspapers use Nastaliq, the flowing, slanted style. In Pages, Word or any app with a font menu:

1. Select your Urdu text.
2. Choose a Nastaliq font. Recent versions of macOS include one. Look for "Nastaliq" in the font list or in the **Font Book** app, where some fonts are listed as available to download. **Noto Nastaliq Urdu** is free from Google Fonts if your Mac does not have one.
3. Make the paragraph right-to-left. In Pages, use the paragraph direction button in the **Format → Text** panel. In Word, use **Right-to-left Text Direction** on the **Home** tab.

Nastaliq is tall, so give it generous line spacing.

## Troubleshooting

**I cannot find Urdu in the list.** Type the word "Urdu" into the search box rather than scrolling. If it is still missing, check that macOS is up to date.

**Keys type the wrong letters.** Look at the Input menu in the menu bar: you may have switched to a different keyboard. Press <kbd>Control</kbd> + <kbd>Space</kbd> to switch back.

**Urdu letters are not joined.** The app is using a font that does not support Urdu, or it does not support right-to-left text. Change the font, or write in the [online keyboard](/urdu) and paste the result into an app that supports Urdu, such as Pages, Notes or Word.

**I only need Urdu now and then.** Then you may not need to install anything. Keep the [online Urdu keyboard](/urdu) as a bookmark: it saves your text on your Mac as you type, and you can download it as Word, PDF or plain text.
