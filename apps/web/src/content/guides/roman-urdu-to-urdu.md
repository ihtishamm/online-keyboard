Roman Urdu is Urdu written with English letters: `aap kaise hain`, `mujhe nahi pata`, `bht shukriya`. Most of us write it every day on WhatsApp because it is quick to type on any keyboard. But a CV, a school assignment, a shop sign or a message to an elder often needs proper Urdu script: <span lang="ur">آپ کیسے ہیں</span>.

You do not need to learn an Urdu keyboard layout to get there. The [Roman Urdu keyboard](/urdu/roman) turns each word into Urdu as you type it, spelled the way you already spell it in chats.

## How it works

1. Open the [Roman Urdu keyboard](/urdu/roman).
2. Type a word in English letters, for example `mera`.
3. Press <kbd>Space</kbd>. The word becomes <span lang="ur">میرا</span> and you carry on with the next one.

While you type, a bar above the keyboard shows the Urdu spellings it thinks you mean, numbered from 1. The first one is used when you press <kbd>Space</kbd>. If you meant another, press its number, or tap it on a phone.

| You type                       | You get                                        |
| ------------------------------ | ---------------------------------------------- |
| `mera naam ali hai`            | <span lang="ur">میرا نام علی ہے</span>         |
| `aap kaise hain`               | <span lang="ur">آپ کیسے ہیں</span>             |
| `mujhe urdu likhna pasand hai` | <span lang="ur">مجھے اردو لکھنا پسند ہے</span> |
| `bht shukriya`                 | <span lang="ur">بہت شکریہ</span>               |

The converter knows about 100,000 Urdu words and how often each is used, so it can tell which of several possible spellings is a real word. That is why `kitab` and `kitaab` both give <span lang="ur">کتاب</span>, and why dropped vowels are fine: `bht`, `bohat` and `bahut` all become <span lang="ur">بہت</span>.

## Letters that need a little care

Most letters work as you would expect. A few sounds can be written more than one way in Urdu, and these are the ones to know.

| Type                          | For                                                                                                        | Example                                                                                    |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `kh`                          | <span lang="ur">خ</span> or <span lang="ur">کھ</span>                                                      | `khush` → <span lang="ur">خوش</span>, `khaana` → <span lang="ur">کھانا</span> (2nd choice) |
| `gh`                          | <span lang="ur">غ</span> or <span lang="ur">گھ</span>                                                      | `ghalat` → <span lang="ur">غلط</span>, `ghar` → <span lang="ur">گھر</span>                 |
| `sh`                          | <span lang="ur">ش</span>                                                                                   | `shaam` → <span lang="ur">شام</span>                                                       |
| `ch`, `chh`                   | <span lang="ur">چ</span>, <span lang="ur">چھ</span>                                                        | `chalo` → <span lang="ur">چلو</span>, `chhota` → <span lang="ur">چھوٹا</span>              |
| `th`                          | <span lang="ur">تھ</span> or <span lang="ur">ٹھ</span>                                                     | `tha` → <span lang="ur">تھا</span>, `theek` → <span lang="ur">ٹھیک</span>                  |
| `bh`, `ph`, `jh`, `dh`        | <span lang="ur">بھ</span>, <span lang="ur">پھ</span>, <span lang="ur">جھ</span>, <span lang="ur">دھ</span> | `phir` → <span lang="ur">پھر</span>, `mujhe` → <span lang="ur">مجھے</span>                 |
| `aa`                          | <span lang="ur">ا</span>, or <span lang="ur">آ</span> at the start                                         | `baat` → <span lang="ur">بات</span>, `aaj` → <span lang="ur">آج</span>                     |
| `ee`, `i`                     | <span lang="ur">ی</span>                                                                                   | `teen` → <span lang="ur">تین</span>                                                        |
| `e`, `ay` at the end          | <span lang="ur">ے</span>                                                                                   | `mere` → <span lang="ur">میرے</span>, `bachay` → <span lang="ur">بچے</span>                |
| `oo`, `o`, `u`                | <span lang="ur">و</span>                                                                                   | `door` → <span lang="ur">دور</span>, `ko` → <span lang="ur">کو</span>                      |
| `n` at the end, after a vowel | <span lang="ur">ں</span>                                                                                   | `main` → <span lang="ur">میں</span>, `kahan` → <span lang="ur">کہاں</span>                 |

### Capital letters for ٹ ڈ ڑ and friends

English has one `t`, Urdu has <span lang="ur">ت</span> and <span lang="ur">ٹ</span>. Usually the converter works out which one you mean from the word. When it does not, a capital letter inside the word asks for the second letter:

| Capital | Letter                   | Example                                                                             |
| ------- | ------------------------ | ----------------------------------------------------------------------------------- |
| `T`     | <span lang="ur">ٹ</span> | `kaTna` → <span lang="ur">کاٹنا</span> (`katna` gives <span lang="ur">کتنا</span>)  |
| `D`     | <span lang="ur">ڈ</span> | `anDa` → <span lang="ur">انڈا</span> (`anda` gives <span lang="ur">اندا</span>)     |
| `R`     | <span lang="ur">ڑ</span> | `baRa` → <span lang="ur">بڑا</span>, `paRhna` → <span lang="ur">پڑھنا</span>        |
| `S`     | <span lang="ur">ص</span> | `naSeeb` → <span lang="ur">نصیب</span> (`naseeb` gives <span lang="ur">نسیب</span>) |
| `Z`     | <span lang="ur">ض</span> | `faZool` → <span lang="ur">فضول</span>                                              |
| `H`     | <span lang="ur">ح</span> | `saHeeh` → <span lang="ur">صحیح</span> (`saheeh` gives <span lang="ur">سہیہ</span>) |
| `N`     | <span lang="ur">ں</span> | `kahaN` → <span lang="ur">کہاں</span>                                               |
| `G`     | <span lang="ur">غ</span> | `baGh` → <span lang="ur">باغ</span>                                                 |

A capital as the **first** letter of a word is ignored, because phones capitalise the start of every sentence on their own. For a word that starts with one of these letters, pick it from the bar instead.

## When it picks the wrong word

Some Roman spellings stand for more than one Urdu word, and the converter goes with the more common one. A few you will meet:

- `haal` gives <span lang="ur">ہال</span> (a hall) first. Press <kbd>2</kbd> for <span lang="ur">حال</span>, as in "kya haal hai".
- `subah` gives <span lang="ur">صوبہ</span> (a province) first. Press <kbd>2</kbd> for <span lang="ur">صبح</span> (morning).
- `bhai` gives <span lang="ur">بھی</span> (also) first. Type `bhaai` for <span lang="ur">بھائی</span> (brother), or pick it from the bar.
- `khana` gives <span lang="ur">کہنا</span> (to say). Type `khaana` and choose <span lang="ur">کھانا</span> (food).

The fix is always the same: look at the bar before you press <kbd>Space</kbd>. Spelling long vowels in full (`aa`, `ee`, `oo`) also helps the converter tell similar words apart.

## English words, names and numbers

- To keep a word in English, press <kbd>Esc</kbd> instead of <kbd>Space</kbd>. The word stays as you typed it.
- Press <kbd>Esc</kbd> when you are not in the middle of a word to switch to English typing for a while. Press it again to come back to Urdu.
- Common English words that Urdu has borrowed come out in Urdu script: `school` → <span lang="ur">اسکول</span>.
- Well-known names (`pakistan`, `karachi`, `lahore`) convert correctly. Less common names may need picking from the bar, because a name can be spelled several ways in Urdu.
- Full stops, commas and question marks become their Urdu forms: <span lang="ur">۔</span> <span lang="ur">،</span> <span lang="ur">؟</span>.

## What it does not do

The converter works word by word while you type. Text you paste in stays as it is, so to convert a long Roman Urdu message you need to type it, not paste it. It also cannot always guess spellings it has never seen, such as rare names or slang. When that happens, the bar shows its best attempts and you can pick the closest, or switch to the [Phonetic layout](/urdu) to type the word letter by letter.
