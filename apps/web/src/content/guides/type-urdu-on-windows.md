Windows can type Urdu without any extra software. You add Urdu as a keyboard language, then switch to it with a shortcut whenever you want to write in Urdu. This guide covers Windows 11 and Windows 10, the two keyboard layouts you will come across, and how to make Urdu look right in Word.

**Short on time?** You can type Urdu straight away in your browser with the [online Urdu keyboard](/urdu), then copy the text into any program. Nothing to install.

## Add the Urdu keyboard on Windows 11

1. Press <kbd>Windows</kbd> + <kbd>I</kbd> to open **Settings**.
2. Choose **Time & language**, then **Language & region**.
3. Next to **Preferred languages**, select **Add a language**.
4. Type `Urdu` in the search box, select **Urdu**, then **Next**.
5. On the next screen you can untick the extras (speech, handwriting, display language) if you only want the keyboard. Select **Install**.

Windows adds Urdu to your languages with its Urdu keyboard. To check, select the **⋯** button next to Urdu, then **Language options**: under **Keyboards** you should see **Urdu**.

## Add the Urdu keyboard on Windows 10

1. Press <kbd>Windows</kbd> + <kbd>I</kbd> and choose **Time & Language**, then **Language**.
2. Under **Preferred languages**, select **Add a language**.
3. Search for **Urdu**, select it, then **Next** and **Install**.

Menu names move a little between Windows updates. If you cannot find a step, open the Start menu and search for "language settings".

## Switch between English and Urdu

Once two keyboards are installed, a language button appears on the taskbar, next to the clock. Select it to choose a keyboard, or use a shortcut:

- <kbd>Windows</kbd> + <kbd>Space</kbd> moves to the next keyboard. Hold <kbd>Windows</kbd> and keep tapping <kbd>Space</kbd> to pick from the list.
- <kbd>Left Alt</kbd> + <kbd>Shift</kbd> also switches language, unless it has been turned off.

Windows remembers the keyboard per program in some setups, so if you switch in Word and then open Notepad, check the taskbar button before you type.

## Standard or Phonetic: which layout is this?

The keyboard Windows installs is the **Standard** Urdu layout, the one many offices and newsrooms learnt on. Its keys are arranged by how often letters are used, not by how they sound, so the letters will not match the English letters printed on your keys. You can see the whole layout on our [Standard layout chart](/cheat-sheets/urdu-standard).

Many people find the **Phonetic** layout easier: letters sit on the English keys that sound like them, so <kbd>s</kbd> types <span lang="ur">س</span>, <kbd>k</kbd> types <span lang="ur">ک</span> and <kbd>Shift</kbd> + <kbd>t</kbd> types <span lang="ur">ٹ</span>. Windows does not include a Phonetic Urdu layout. You have two options:

- **Use it online.** The [Urdu keyboard](/urdu) here uses the Phonetic layout by default, with the keys shown on screen as you type. Copy the text when you are done.
- **Install one.** Phonetic Urdu keyboards for Windows have been published by Pakistani language research groups and others. Install keyboard software only from a source you trust, because it runs inside every program you type in.

Whichever layout you choose, keep a printed chart beside your keyboard for the first week. There are free printable charts for [Phonetic](/cheat-sheets/urdu-phonetic) and [Standard](/cheat-sheets/urdu-standard).

## Make Urdu look right in Word

Urdu text is often shown in Naskh, a plain style common in Arabic, when most Urdu readers expect Nastaliq, the flowing calligraphic style of Urdu books and newspapers. To get Nastaliq in Microsoft Word:

1. Select your Urdu text.
2. Choose a Nastaliq font. Windows includes **Urdu Typesetting**. **Noto Nastaliq Urdu** is free to download from Google Fonts.
3. Set the paragraph direction to right-to-left with the **Right-to-left Text Direction** button on the **Home** tab, or press <kbd>Ctrl</kbd> + <kbd>Right Shift</kbd>.

Nastaliq needs more line spacing than English. If letters at the top or bottom are cut off, increase the line spacing to 1.5 or set it to "Multiple" rather than "Exactly".

If you would rather skip all of this, write in the [online Urdu keyboard](/urdu), which shows Nastaliq as you type, and use **Download → Word (.docx)**. The file opens in Word with the Urdu font and right-to-left direction already set.

## Troubleshooting

**I pressed keys and got English letters.** The keyboard is still on English. Check the language button on the taskbar, then press <kbd>Windows</kbd> + <kbd>Space</kbd>.

**Urdu appears as empty boxes.** The program's font has no Urdu letters. Change the font to Urdu Typesetting, Noto Nastaliq Urdu or Segoe UI.

**Letters come out in the wrong order with English mixed in.** Set the paragraph to right-to-left (see above). Mixed Urdu and English in one line is normal: the Urdu reads right to left and the English words keep their own order.

**Where are zabar, zer and pesh?** On the Windows Standard layout, diacritics are on the <kbd>AltGr</kbd> (right <kbd>Alt</kbd>) layer. The [Standard chart](/cheat-sheets/urdu-standard) shows each one.
